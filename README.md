# Influencer search

A brief-driven creator shortlist: requirements written as pass/fail lines, a numbers check on every candidate, a visual review on contact sheets, and a workbook rebuilt on every add. Start with `CLAUDE.md`, then `skills/`.

The template ships the brief structure, the review workflow and the scoring and workbook code. It does not ship platform automation; plug in a data source you are allowed to use (see `CLAUDE.md`).

---

Part of [citadel-template](https://github.com/jeff0229/citadel-template), which also holds the knowledge library this system plugs into.
